# Calcul IMC – Application Android

## Description
Application Android permettant de calculer l’Indice de Masse Corporelle (IMC) à partir du poids et de la taille.

## Fonctionnalités
- Calcul automatique de l’IMC.
- Affichage de la catégorie avec un indicateur coloré.
- Conversion automatique de la taille en cm vers m.
- Partage du résultat.
- Historique des 5 derniers calculs.
- Conservation du résultat après rotation de l’écran.

## Technologies
- Kotlin
- XML
- Android Studio
- SharedPreferences

## Formule
IMC = Poids (kg) / Taille (m)²
